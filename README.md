# egos-portfolio

Portfólio pessoal moderno desenvolvido com HTML, CSS e JavaScript, com design responsivo, navegação fluida e seção de projetos.

## Sobre o projeto

Este repositório contém o meu portfólio pessoal, criado para apresentar minha formação, habilidades, experiência, projetos e formas de contato de maneira profissional e responsiva.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Funcionalidades

- Layout responsivo para celular e computador.
- Navegação com menu interativo.
- Seção de projetos com cards clicáveis.
- Exibição de formação, experiência e habilidades.
- Ícone personalizado na aba do navegador.

## Projetos

- [Catálogo de Vendas de Pré Moldados](https://catalogo-vendas-beta.vercel.app)
- [Dashboard de Usuário](https://card-user-theta.vercel.app)
- [Vendas de Pudim](https://vendas-pudim.vercel.app)

## Como executar

1. Clone o repositório:
```bash
git clone https://github.com/egos404/egos-portfolio.git
```

2. Abra a pasta do projeto.

3. Execute em um servidor local, como Live Server, ou abra o arquivo `index.html` no navegador.

## Estrutura do projeto

```bash
egos-portfolio/
├── index.html
├── style.css
├── script.js
└── assets/
    └── favicon.ico
```
